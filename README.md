# Personal Event Planner

## Overview

Personal Event Planner is a React application that allows users to create, organise, edit and delete their personal events.

## Features

- Registration for new users and log in for returning users.
- Adding and managing events on Dashboard
- Editing and deleting existing events.
- Help page to guide users with navigating the app.

## Technologies

- React
- Vite
- JavaScript
- CSS

## How to run the application

The user creates an account by entering the required information in the registration form. A registered user can log in to access their account with upcoming events if there are any.

 In a user's dashboard, there's the user's upcoming events.User can add new events or edit or delete existing ones. 

 The Help Link is where the user can get help with navigating the app.
